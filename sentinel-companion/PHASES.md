# Companion release acceptance

1. Foundation: personal plugin manifest and marketplace registration; source and portable instructions included. No public server required for this version.
2. Connection: use the existing official Robinhood tool connection. Verified locally with read calls. Each different ChatGPT environment must independently expose and authorize Robinhood.
3. Operating rules: research default, kill switch engaged, exact final owner approval, conservative checked limits, autonomous unavailable.
4. Dashboard: official broker observations rendered with time and coverage errors. Static snapshot refresh is performed by ChatGPT/Codex tool calls. No simulation account.
5. Committee: repeatable four-perspective model workflow, sources, dissent, no-trade alternative, and structured proposals. Not four independent AI services.
6. Risk and journal: deterministic advisory checker, serialized SQLite state transitions and hash-linked events. Not a broker-enforced hard gate or cross-device history service.
7. Approval: skill guides official preview, final owner confirmation, submission with stable ref_id, order verification and uncertain-order recovery. Lifecycle helper tested without placing any broker orders.
8. Validation: numerical checks, journal lifecycle, corruption detection, account redaction, dashboard escaping, plugin validation and live read calls. No live trade was performed. Cloud sharing/import and live execution acceptance remain user-dependent; do not label this fully production-tested trading software.

This release implements the selected companion scope. Original requests for an independent enforced server risk gate, autonomous execution, a live continuously polling GUI, and automatic global access are not features of this companion.
